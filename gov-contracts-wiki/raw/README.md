# raw/ — source documents

Drop source material here: award documents, mods, RFPs/RFQs, SOWs/PWSs,
meeting notes, exported emails, spreadsheets. Any format is fine; PDFs
and text-based formats work best.

Rules:
- **Immutable.** Once a file is here, nobody (human or agent) edits it.
- **Name with a date prefix** when you can: `2026-07-01-mod-p00003.pdf`.
  It keeps the folder and the summaries sortable.
- After adding files, tell the agent: *"ingest the new files in raw/"*.

⚠️ Do not put CUI, classified, source-selection-sensitive, or
NDA-covered material here. See the sensitivity note in the main README.
